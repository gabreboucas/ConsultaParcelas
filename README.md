## 🇧🇷 Sobre o Projeto

O **Consulta Prazos** é um **aplicativo Web e Mobile** para **mercados e estabelecimentos comerciais**, permitindo que clientes com **pagamentos pendentes** realizem quitação de forma rápida e segura.

💳 Métodos de pagamento disponíveis: **PIX** e **Boleto Bancário**  
🔗 Integração completa com a **API Canvi** desenvolvida em **PHP**.  

---

### ✨ Funcionalidades
- 📋 **Listagem** de pagamentos pendentes.
- 📲 **QR Code** para pagamento via PIX.
- 🧾 **Emissão de boleto bancário**.
- 🔗 Integração direta com **API Canvi**.
- 💻 **Compatível** com Web e Mobile (FlutterFlow + Flutter).

---

### 🚀 Como Começar

#### Pré-requisitos
- Flutter **stable** instalado
- Conta no **FlutterFlow**
- API Canvi configurada e rodando
- Chaves de integração (PIX e Boleto)

## 🇺🇸 About the Project
Consulta Prazos is a Web and Mobile app for supermarkets and retail stores, allowing customers with pending payments to settle them quickly and securely.

### 💳 Payment Methods: PIX and Bank Slip (Boleto)
🔗 Fully integrated with the Canvi API developed in PHP.

### ✨ Features
📋 List pending payments.

📲 Generate QR Code for PIX payments.

🧾 Issue bank slips.

🔗 Direct integration with Canvi API.

💻 Works on both Web and Mobile (FlutterFlow + Flutter).

### 🚀 Getting Started
Requirements
Flutter stable installed

FlutterFlow account

Canvi API set up and running

Integration keys (PIX and Bank Slip)

git clone https://github.com/user/ConsultaParcelas.git

# Navigate to the project folder
